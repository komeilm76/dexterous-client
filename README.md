# Dexterous Client 🚀

Dexterous Client is a blazing-fast starter template for modern web projects, built to help you start developing immediately without boilerplate hassle.

## ✨ Features
- **Bun**, **Vite**, **Vue**, **Vuetify**, **Tailwind** for ultra-fast development ⚡
- **Pinia** for state management 🗃️
- **Zod** for validation ✅
- **Alova / Axios** for API requests 🌐
- Micro-services structure for scalable apps 🏗️

## ⚙️ Scripts
```bash
# Start development server with watchers
bun run dev

# Build project
bun run build

# Preview production build
bun run preview

# Type check
bun run type-check

# Lint and fix code
bun run lint

# Generate micro worker
bun run generate-worker

# Watch and generate micro worker
bun run generate-worker:watch

# Watch and generate palette
bun run generate-palette:watch
```

## 🚀 Quick Start
```bash
# Clone repository
git clone <repo-url>
cd dexterous

# Install dependencies
bun install

# Start development server
bun run dev
```
