# dexterous-client
Dexterous is a high-performance starter template for modern web projects. Built with Bun, Vite, Vue, Vuetify, and Tailwind for speed and flexibility. State, validation, and data flow powered by Pinia, Zod, and Axios via Alova. Designed with a micro-services mindset for scalable production systems. Ready to develop, deploy, and grow — instantly.
